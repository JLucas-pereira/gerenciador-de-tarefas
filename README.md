# Gerenciador de Tarefas (CLI)

Aplicativo de terminal em Python para organizar tarefas do dia a dia.

## Funcionalidades
- Adicionar, listar, concluir e remover tarefas
- Salva tudo em um arquivo JSON (os dados não se perdem ao fechar)

## Como executar
Requisito: Python 3 instalado.

```bash
python gerenciador_de_tarefas.py
```

## O que pratiquei
Funções, listas e dicionários, laços, tratamento de erros, leitura/escrita de arquivos JSON.

## Ideias de melhoria
- Data limite e prioridade
- Filtrar tarefas pendentes
- Testes com `pytest`
